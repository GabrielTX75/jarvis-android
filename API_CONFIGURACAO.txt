JARVIS ANDROID — CONFIGURAÇÃO DA IA
Versão do projeto: 0.7.0

1. Abra o JARVIS e entre em Configurações.
2. Em Provedor de IA, selecione “API compatível (Groq, OpenAI ou servidor local)”.
3. O padrão do APK é Groq: https://api.groq.com/openai/v1/chat/completions. Você pode trocar pelo endpoint completo de outro provedor compatível com OpenAI.
4. O modelo padrão configurado é openai/gpt-oss-120b. Confirme no painel do provedor se ele está disponível para sua conta.
5. Se o servidor exigir autenticação, informe a chave no campo temporário.
6. Toque em “Testar conexão com a IA”.
7. Se aparecer “Conectado”, envie uma mensagem normal ao JARVIS.

COMO INTERPRETAR ERROS
- URL inválida: endereço digitado incorretamente.
- HTTP 401/403: chave ausente, incorreta ou sem permissão.
- HTTP 404: rota ou modelo não encontrado; confira o endpoint completo.
- HTTP 429: limite de uso ou créditos atingidos.
- HTTP 5xx: falha no servidor do provedor.
- Falha de conexão/CORS: servidor inacessível, política CORS ou rede.
- Modelo não retornou texto: resposta não veio no formato esperado ou modelo incorreto.

SEGURANÇA
- Não envie sua chave de API em prints, conversas ou arquivos públicos.
- No Android, a chave é armazenada no armazenamento criptografado do sistema. No navegador comum, ela permanece apenas na sessão.
- Não coloque uma chave secreta dentro do APK para distribuir a outras pessoas.
- Para um app público, crie um backend HTTPS e mantenha a chave somente no servidor.
- HTTP é bloqueado para servidores externos; somente localhost/127.0.0.1 é liberado para testes locais.

COMPATIBILIDADE
Esta versão usa o formato de chat compatível com OpenAI. APIs de fornecedores que usam outro formato precisam de um adaptador/backend. Não basta colar qualquer API key: endpoint, modelo, autenticação e formato precisam corresponder.


COFRE DE APIs (versão em desenvolvimento)
- APK: Configurações > Chaves e Senhas. Groq, Gemini, Tavily e brapi são guardadas no armazenamento criptografado AndroidX Security.
- Windows: Configurações. As mesmas credenciais são guardadas no Windows Credential Manager via keyring.
- Deixe os campos vazios para manter a chave existente. O botão de apagar remove as credenciais de API.
- Use os botões Testar para validar cada credencial. O teste não revela nem envia a chave ao chat.
- Não envie chaves por conversa, prints ou arquivos. APK e EXE mantêm cofres separados até a sincronização ser construída.
